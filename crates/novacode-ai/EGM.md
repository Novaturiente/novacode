# novacode-ai

## Overview

Crate `novacode-ai`: the provider layer (L2) of novacode. It depends on
`novacode-types` and `novacode-base` and talks to model providers over
`reqwest`. The `data/` folder holds the bundled `models.json` and
`profiles.json` snapshots, compiled into the crate by `src/catalog.rs`
(regenerated by `scripts/gen-catalog.py`).

## Subdirectories & Boundaries

- src: [./src/EGM.md](./src/EGM.md) - `Adapter` trait and wire adapters
  (Anthropic, OpenAI Chat/Responses, Gemini, Copilot, process providers),
  `Providers`/`Route` resolution, `AuthStore` credentials and account
  rotation, model `Catalog`, retry, schema repair, cross-model transform,
  classifiers, quota and tracing.
- data: bundled model and profile metadata (not a code contract).

## Verification
