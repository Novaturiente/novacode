## extensions/lsp/src/EGM.md

  - The `waitMs` wait is applied once per touched file, inside the loop over paths (`extensions/lsp/src/lsp.rs:535`, `:557`). A call that touches N files can wait N×`waitMs`.

  - Yet the warning flag is still set (`extensions/lsp/src/lsp.rs:566`), and the start failure is cached (`extensions/lsp/src/lsp.rs:547`, `:526`).
  - So in that case the model never sees either message; the start failure reaches stderr only.
  - **Fix:** document that a failure or health notice first seen on a `read` goes to stderr only, or keep the flag and the cached failure from being consumed when `baseline_only` is true.
